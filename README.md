# Grand Hotel Management System

A full-stack, component-based web application that digitizes the day-to-day operations of a five-star hotel: reservations, guests, staff, kitchen, security and billing.

Built for the **Component-Based Computing (CS344)** course at MSA University.

## Features

- User authentication (login / logout)
- Role-based dashboards, each with its own sidebar and limited access scope
- Reservation management (create, view, delete)
- Guest management
- Billing operations
- Modular, component-based design with REST APIs between layers

## Architecture

The system follows a 3-layer architecture:

1. **Presentation layer**: HTML / CSS / JavaScript frontend
2. **Application layer**: Java Spring Boot backend (Controller, Service, Repository)
3. **Data layer**: MySQL database (Hibernate ORM + Spring Data JPA)

### Components

| Component | Sub-components |
|---|---|
| **Services** | Front Desk & Reception, Spa & Recreation, House Keeping, Concierge, Reservations, Maintenance & Engineering |
| **Customer Data** | Reservation, Data, Billing System |
| **Security** | Access Control, Incident Report |
| **Billing & Finance** | Accounting, Sales & Events, Billing & Payment |
| **Kitchen** | Menu Manager, Room Service, Recipe & Inventory, Food & Equipment Restock, Orders |
| **Staff Management** | Employees, Roles, Shifts Scheduling |
| **Database** | Shared storage for Customer Data, Billing & Finance and Staff Management |
| **External Payment Gateway** | Payment processing with the guest's bank |

Components talk to each other only through **provided / required interfaces** (see the component diagram below).

### Design principles

- **Inversion of Control (IoC)**: Spring Boot manages component lifecycles
- **Dependency Injection (DI)**: services are injected through `@Autowired` on interface types, not concrete classes
- **Interface-based design**: each component exposes its functionality through Java interfaces
- **Separation of concerns**: each package handles one business domain

## Database

Main tables (auto-generated by Hibernate):

- `users` (id, username, password, role)
- `guests` (id, name, email, phone)
- `reservations` (id, check_in, check_out, guest_email, room_type)

## REST API

| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/auth/login` | User login |
| GET | `/api/reservations` | Get all reservations |
| POST | `/api/reservations` | Create a reservation |
| DELETE | `/api/reservations/{id}` | Delete a reservation |

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/FarahKinaz2005/hotel-management-system-using-Java.git
   ```
2. Create a MySQL database and update the connection settings (URL, username, password) in `application.properties`.
3. Open the project in Eclipse (or any Java IDE) as a Maven/Spring Boot project.
4. Run the main Spring Boot application class.
5. Open `http://localhost:8080/app.html` in your browser and sign in.
